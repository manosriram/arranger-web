THE QUEUE

Not a wall of terminals. A list of who's waiting on you.

Five agents running is easy. Knowing which one has been stuck on a permission prompt for twenty minutes is the hard part. arranger watches every edit, command and question and sorts the room by that.

  • Approve, deny or answer in place. Permission requests and questions surface at the top with what the agent wants to do. ⌘1 ⌘2, or J K to jump between the ones that need you.
  • Your agent, unwrapped. Claude Code and Codex keep their own interface, slash commands and keys. arranger listens through the agents' hooks; it doesn't put a chat window in front of them.
  • Every machine in one list. Agents on your laptop, a GPU box and a dev server sit side by side, grouped by machine.
  • Revive or clone a take. An ended agent resumes its last session in the same worktree; ⌘D forks a task, chat and edits included, to try another approach or model.
  • Keyboard first, or no window at all. Vim keys are one toggle away, and every action works from the shell: arranger ls, approve 3, commit 3 --pr.

REVIEW

Know what was checked before you merge.

A green diff isn't proof. Review puts the change beside the latest result of every test, build and lint command the agent ran in that worktree, so you see what failed, what it fixed, and what it never ran.

  • Notes go back to the agent. Comment on a line and send it. The agent picks up where it was, in the same worktree.
  • Run your own checks. arranger run 3 cargo test runs in the task's checkout, uncommitted edits included, and keeps the exit status, so a script can gate the merge.
  • Revert by hunk. Keep the good part of a change without starting over.

Merges are all or nothing

A merge that would conflict is backed out. Your base branch is never left half merged.

Conflicts go back to the agent

They land in the task's worktree, and Review can hand them to the agent that wrote the change.

YOUR MACHINES

Close the lid. The remote section keeps playing.

A small daemon owns the agents, not the window. Close the window and local agents keep working. Close the lid and agents on your SSH machines keep working too, and they're waiting in the queue when you open it again.

Add a GPU box or a dev server with arranger machine add. arranger uses your own ssh, keys and ~/.ssh/config, forwarding a socket over it. Nothing listens on the network.
